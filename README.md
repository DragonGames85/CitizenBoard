### Выбор стека:

- Vite (главный сборщик)
- React (главный фреймворк)
- TypeScript (типизированный JavaScript)
- Tailwind CSS (стилизация приложения)
- Recharts (для графиков и статистики)
- React Hook Form (для работы с формами)
- Zod (для валидации формы)
- React Icons (разнообразные иконки)
- Tanstack react-table (для таблицы с данными)
- Tanstack react-virtual (виртуализация больших списков)
- Prettier (чистый и упорядоченый код) + плагины для импортов и tailwind
