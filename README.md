# CitizenBoard

### Инструкция

1. Нужен Node.js.

2. Запустить 2 команды в cmd:

```bash
npm install
npm run dev
```

3. После запуска Vite покажет адрес, обычно http://localhost:5173. По этой ссылке будет запущенное приложение.

### Выбор стека:

- Vite (главный сборщик)
- React (главный фреймворк)
- TypeScript (типизированный JavaScript)
- Tailwind CSS (стилизация приложения)
- Recharts (для графиков и статистики)
- React Hook Form (для работы с формами)
- Zod (для валидации формы)
- React Icons (разнообразные иконки)
- Tanstack react-table (для таблицы с данными)
- Tanstack react-virtual (виртуализация больших списков)
- Prettier (чистый и упорядоченный код) + плагины для импортов и tailwind
- @faker (для работы с фейковыми данными)
- moment.js (для удобной работы со временем (dateTime))
- HeadlessUI (для готовых ui-компонентов)
- Zustand (основной state-менеджер)

### Выбранная архитектура (методология)

*FSD (Feature-Sliced Design)*
Ссылка: https://fsd.how/ru/docs/get-started/overview/

Почему: легко масштабировать, поддерживать код и ориентироваться.

```
src/
├── app/
│   ├── providers/          AppLayout, AppProviders
│   ├── router/
│   ├── styles/
│   ├── ui/                 Sidebar
│   └── App.tsx
├── pages/
│   ├── dashboard/ui/
│   ├── citizens/ui/
│   └── citizen-details/ui/
├── features/
│   ├── filter-citizens/    ui, model
│   ├── edit-citizen/       ui, model
│   ├── manage-family-members/  ui, model
│   └── manage-documents/   ui, model
├── entities/
│   └── citizen/
│       ├── api/            данные и zustand-стор
│       ├── model/          типы, статистика
│       └── ui/
└── shared/
    ├── consts/
    ├── lib/
    └── ui/                 Button, Input, Select, Table и др.
```

`app` - главный слой приложения: роутер, стили, макет, сайдбар.
`pages` — страницы.
`features` — фильтры, форма редактирования гражданина и члены семьи.
`entities/citizen` — модель и хранение сущностей.
`shared` — общие helpers и компоненты.
